# 1 · 计划 — 深色模式开关（示例）

> 来源：`ISSUES.md` #1「深色模式，晚上看着刺眼」。拆解判型：一个版本能交付完 → 简单 task，先过三件套再开发。

## task 一段话

在设置里加一个「深色模式」开关，切换后全站配色切深色，选择本地持久化、下次打开保持。

## 验收点

1. 设置页有开关，切换立即生效。
2. 刷新 / 重启后保持上次选择。
3. 浅色模式不受影响。

## 不做什么（范围边界）

- 不做跟随系统自动切换（记回池子，下一迭代）。
- 不做多主题（只深 / 浅两套）。

## 怎么拆

1. 定义深色配色变量。
2. 加开关 UI + 状态。
3. 持久化（localStorage）。
4. 启动时读取并应用到根节点。
